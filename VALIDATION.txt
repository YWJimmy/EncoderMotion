EncoderMotion v5 validation record

Static validation:
- motion.c, serial_log.c, empty.c and app_tick.c pass strict C11 syntax checks.
- app_tick pending periods are coalesced instead of replayed.
- speed samples are divided by actual elapsed SysTick periods.
- PI and synchronization integrals use elapsed-time scaling with a bounded gain step.
- encoder-fault timing uses real elapsed periods and a startup grace interval.
- no patch files are included.
- all ZIP entry names are ASCII.

Host plant regression results:
- Straight 3000 mm with a simulated 40 ms block every 500 ms:
  DONE, left=21248, right=21247, difference=1, ef=0.
- 90 degree turn with the same blocking pattern:
  DONE, left=-626, right=626, ef=0.
- 350 ms simulated motor startup delay:
  DONE without false encoder fault.
- Frozen left encoder:
  ENCFAULT, ef bit 0 set, both PWM outputs zero.
- app_tick unit test:
  three interrupts before servicing produce one pending control request and two overruns.

Target-board validation still required:
- CCS/MSPM0 SDK full build.

- Verify occasional dt > 1 does not stop motion.
- Verify a real disconnected encoder still produces ENCFAULT.
