Validation performed
====================
- Strict C11 syntax validation with MSPM0 API stubs.
- Exhaustive 16-state transition-table test.
- Stationary 00<->01 bounce test: committed count remains zero.
- Stationary 00<->10 bounce test: committed count remains zero.
- Forward full-cycle test: every four valid transitions commits +4.
- Reverse full-cycle test: every four valid transitions commits -4.
- Invalid two-bit jump test: state resynchronises, accumulator resets, count unchanged.
- Atomic snapshot test: both deltas are captured and cleared together.
- Delayed SysTick test: multiple interrupts produce one pending control update.
- Position-controller host model tests: forward, reverse, left turn and right turn.

Target-board build and real-wheel tests are still required because the container does
not contain the exact CCS compiler, MSPM0 SDK generated files or physical hardware.
